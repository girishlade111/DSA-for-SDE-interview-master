# DSA for SDE Interview

A topic-organized collection of Data Structures and Algorithms notes plus runnable code samples for Software Development Engineer interview preparation.

Full notes live in [`DSA-for-SDE-interview-master/`](./DSA-for-SDE-interview-master/) with per-topic folders; each folder contains implementations in Python and Java plus short topic READMEs.

## Contents

- Linked Lists
- Stack and Queue
- Trees and Graphs (BFS, DFS, cycle detection, MST, shortest path)
- Hashing
- Heaps
- Recursion and Greedy algorithms
- Sorting and Searching algorithms
- Strings and Matrices
- Bit manipulation

## Tech Stack

Python · Java · Markdown notes

## Quick Start

No build step required. Browse any topic folder and run the sample directly:

```bash
ls "DSA-for-SDE-interview-master"
python "DSA-for-SDE-interview-master/Bit Manipulation/countSetBits.py"
```
