# DSA-for-SDE-interview

Data Structures and Algorithms notes + code for SDE role preparation.

> Full notes in `DSA-for-SDE-interview-master/` with per-topic folders.

## Contents
- Linked Lists, Stack, Queue, Trees, Graphs, Hashing, Heaps, Recursion
- Sorting / Searching, String, Matrices, Bit Manipulation, Greedy
- Sample implementations in Python / Java

## Usage
```bash
ls DSA-for-SDE-interview-master
python DSA-for-SDE-interview-master/"Bit Manipulation"/countSetBits.py
```

No build required.
